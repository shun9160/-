# MT5 自動連携（EA）の入れ方

MT5に小さなプログラム（EA）を入れると、**取引を決済するたびに自動でアプリへ記録**されます。
スクショの読み取りと違い、S/L・T/P・手数料・スワップまで**正確な数値**がそのまま入ります。

- 費用：無料
- パスワードなどを外部サービスに渡しません（あなたのPCから直接送信します）
- **MT5を起動している間**に動きます。閉じている間の取引は、次に起動したときにまとめて送られます

---

## 1. 準備するもの

Supabaseの画面（**Project Settings → API**）から2つをコピーしておきます。

| Supabaseの表示 | 使う場所 |
|---|---|
| **Project URL**（`https://xxxx.supabase.co`） | EAの `SupabaseUrl` |
| **anon public** キー（`eyJ...`） | EAの `SupabaseAnonKey` |

## 2. EAファイルを置く

1. MT5を開き、**[ファイル] → [データフォルダを開く]** をクリック
2. `MQL5` → `Experts` フォルダを開く
3. この `FxJournalSync.mq5` をその中にコピー
4. MT5に戻り、**[ツール] → [MetaQuotes Language Editor]**（または `F4`）を開く
5. 左のツリーから `FxJournalSync.mq5` を開き、**[コンパイル]**（`F7`）を押す
   - 「0 errors」と出れば成功です

## 3. 送信先を許可する（ここが重要）

MT5は既定で外部へ通信しません。許可が必要です。

1. **[ツール] → [オプション] → [エキスパートアドバイザ]** タブ
2. **「WebRequestを許可するURLリスト」にチェック**
3. 一覧に **あなたのSupabase URL** を追加
   ```
   https://vnnsftzzeerbogavzjbq.supabase.co
   ```
   ※ 末尾にスラッシュは付けません
4. **OK** で閉じる

> この設定をしないと「送信できません」とログに出ます。

## 4. EAをチャートに乗せる

1. 適当なチャート（どの通貨ペアでもOK）を開く
2. ナビゲーターの **エキスパートアドバイザ** から `FxJournalSync` をチャートにドラッグ
3. 設定画面が出るので、**パラメータ** タブで入力：

| 項目 | 入れる値 |
|---|---|
| `SupabaseUrl` | `https://xxxx.supabase.co` |
| `SupabaseAnonKey` | `eyJ...`（anon public キー） |
| `DaysToSync` | `30`（何日前までを送るか。初回だけ `365` などにすると過去分もまとめて入ります） |
| `SyncEveryMinutes` | `5`（定期同期の間隔。`0` で定期同期しない） |
| `SyncOnTradeClose` | `true`（決済のたびに送る） |

4. **「アルゴリズム取引を許可する」にチェック**して OK
5. 画面上部の **[アルゴリズム取引]** ボタンが緑（有効）になっていることを確認

## 5. 動いているか確認する

MT5下部の **[ツールボックス] → [エキスパート]** タブにログが出ます。

```
[FxJournal] 開始しました。起動時の同期を実行します。
[FxJournal] 送信しました (HTTP 201)
[FxJournal] 同期完了: 成功 12件 / 失敗 0件
```

アプリ（fx-daily.netlify.app）を開いて、取引が入っていれば成功です。

---

## うまくいかないとき

| ログに出るメッセージ | 対処 |
|---|---|
| `[ツール]→[オプション]... 許可URLに追加してください` | 手順3をやり直してください（URLの綴り・末尾スラッシュなしを確認） |
| `サーバーが受け付けませんでした (HTTP 401)` | `SupabaseAnonKey` が違います。**anon public** キーをコピーし直してください |
| `サーバーが受け付けませんでした (HTTP 404)` | `SupabaseUrl` が違うか、`trades` テーブルが未作成です |
| 何も出ない | EAがチャートに乗っていない／アルゴリズム取引が無効です |

## 仕様メモ

- 送るのは**決済が完了した取引**だけです（保有中のポジションは送りません）
- 時刻はMT5のサーバー時刻を**UTCに直して**送るため、アプリ側で日本時間に正しく変換されます
  （スクショ取り込みのようなドバイ時間の想定は不要です）
- **すでに取り込み済みの取引は上書きしません**。アプリで書いたメモや添付画像を守るためです
- S/L・T/Pは建玉時の注文から取得します。途中で建値へ動かした場合など注文に残らないケースでも、
  決済理由がS/L・T/Pなら決済価格をその水準として記録します
